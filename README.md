Instagram-Style Feed Logic Project

A full-stack web application focusing on the core logic of a social media feed, including dynamic post rendering, user interactions, and a responsive UI.

🚀 Features

Dynamic Feed: Efficiently renders posts with user data, images, and captions.

Interactive Elements: Functional "Like" and "Comment" logic for user engagement.

Real-time Updates: Smooth UI transitions when interacting with the feed.

Responsive Design: Optimized for both mobile and desktop viewing using modern CSS.

🛠️ Tech Stack

Frontend: React.js, Tailwind CSS, Vite

Backend: Node.js, Express

Database: MongoDB (Mongoose)

State Management: React Hooks (useState, useEffect)
